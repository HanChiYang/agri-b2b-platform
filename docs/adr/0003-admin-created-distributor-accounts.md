# ADR-0003：經銷商帳號由管理員在後台建立

- 狀態：已接受
- 日期：2026-10-24

## 背景

平台只給公司既有的合作經銷商使用，不對外開放，經銷商的身分由公司自己確認。

## 決策

- 不提供註冊 API。管理員在後台新增經銷商時，一併建立登入帳號
- 初始密碼由系統隨機產生，只在建立時顯示一次，由管理員用電話或 LINE 等方式告訴經銷商
- 經銷商第一次登入必須改密碼
- 忘記密碼時由管理員重設，規則和初始密碼相同；第一版不做 Email 自助重設

## 考慮過的其他方案

- 經銷商自行註冊，管理員在後台審核：需要註冊頁、審核流程和 Email 驗證，第一版用不到

## 影響

- 功能少，也比較安全，外部的人沒辦法自己建立帳號
- 開帳號和重設密碼都要由管理員處理；經銷商變多時，再考慮加入自助功能
