# ADR-0004：不串接金流，系統只處理訂單

- 狀態：已接受
- 日期：2026-10-24

## 背景

B2B 交易常用匯款、月結等方式付款，這些都在系統之外處理。

## 決策

- 不串接金流
- 訂單只記錄訂了什麼，以及處理到哪個階段（待確認、已確認、已出貨、已完成、已取消），不記錄付款狀態

## 考慮過的其他方案

- 串接綠界、藍新等金流：要簽金流合約、付手續費，還要處理付款通知與退款
- 不串金流，但讓管理員在後台手動標記「已付款」：第一版先不做，需要時再加

## 影響

- 第一版範圍小，下單流程單純
- 對帳要在系統外進行
- 之後要記錄付款狀態，只要在訂單加欄位，不影響現有的狀態流程
