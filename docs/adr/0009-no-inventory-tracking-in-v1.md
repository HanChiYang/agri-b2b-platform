# ADR-0009：第一版不管理庫存

- 狀態：已接受
- 日期：2026-10-24

## 背景

管理庫存要處理下單扣庫存、多人同時下單搶同一批貨、取消時回補、進貨入庫等問題，會讓第一版複雜很多。

## 決策

- 第一版不記錄庫存數量，商品和規格只分上架、下架
- 每張訂單都要經過管理員確認；管理員確認時人工檢查有沒有貨，沒貨就取消訂單或聯絡經銷商
- 暫時缺貨的規格，由管理員先下架

## 考慮過的其他方案

- 下單時直接扣庫存，庫存不夠就不能下單：經銷商可以馬上知道有沒有貨，但要處理併發與回補，也要有人維護正確的庫存數字

## 影響

- 下單流程簡單，不會有超賣的問題
- 庫存要在系統外管理，例如現有的進銷存系統或 Excel
- 之後要加庫存：在 `ProductVariant` 加庫存欄位，下單和取消時更新，並處理併發
