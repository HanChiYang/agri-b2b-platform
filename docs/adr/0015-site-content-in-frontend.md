# ADR-0015：公司簡介、聯絡資訊寫死在前端

- 狀態：已接受
- 日期：2026-10-24

## 背景

原本的計畫是讓管理員在後台編輯公司簡介、聯絡資訊：內容存在 `site_contents` 資料表，提供公開讀取和後台編輯的 API（`docs/plan.md` 階段 7）。

這些內容很少更新。為了它們做資料表、兩支 API、後台編輯畫面和初始資料，工作量和用到的機會不成比例。

## 決策

- 公司簡介、聯絡資訊直接寫在前端，後端不建資料表，也不提供 API
- `docs/plan.md` 的階段 7 取消，保留編號，後面階段的編號不變

## 考慮過的其他方案

- 照原計畫由後台編輯：管理員改內容不用改程式、重新部署，但第一版用不到，等需要時再加

## 影響

- 修改公司簡介、聯絡資訊要改前端程式，再重新部署
- [ADR-0008](0008-prices-visible-after-login.md) 寫的「訪客可以讀取網站內容的 API」不再適用：訪客看的是前端的頁面，後端只開放登入 API 給訪客。ADR-0008 的決策（價格要登入才看得到）不變
- [ADR-0006](0006-single-api-project.md) 資料夾範例中的 `SiteContents/` 不會出現
- 之後要讓管理員編輯時，再新增資料表和 API，寫一份新的 ADR 取代這一份
