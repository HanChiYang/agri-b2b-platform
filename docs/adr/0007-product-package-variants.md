# ADR-0007：商品與包裝規格分開儲存

- 狀態：已接受
- 日期：2026-10-24

## 背景

同一種農藥常有多種包裝容量（例如 250ml、1L），許可證字號、有效成分、劑型都一樣，只有容量和價格不同。

## 決策

- `Product` 存共同的資訊：名稱、農藥許可證字號、有效成分、劑型、廠商、說明、圖片
- `ProductVariant` 存每一種包裝：規格名稱、料號、單價、上下架
- 訂單明細指向 `ProductVariant`
- 只有一種包裝的商品，也建一筆規格

## 考慮過的其他方案

- 每種包裝建成獨立的商品：比較簡單，但許可證字號等資料要重複填，修改時容易漏改

## 影響

- 商品資料不重複，經銷商可以在同一頁選規格
- 後台編輯商品時要一起管理規格，畫面會稍微複雜
- 之後加庫存的話，庫存數量放在 `ProductVariant`
