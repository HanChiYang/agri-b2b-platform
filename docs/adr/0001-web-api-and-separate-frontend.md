# ADR-0001：前後端分離：ASP.NET Core Web API + 獨立前端

- 狀態：已接受
- 日期：2026-10-24

## 背景

平台需要三種畫面：公開的首頁與公司簡介、經銷商的下單頁、管理員的後台。畫面可以由 ASP.NET Core 直接產生（MVC / Razor），也可以讓後端只提供 API，前端另外開發。

## 決策

- 後端做成 ASP.NET Core Web API，只回傳 JSON
- 前台和後台的畫面另外用前端框架開發（React 或 Vue，之後決定）

## 考慮過的其他方案

- ASP.NET Core MVC 一體式：只有一個專案、部署最簡單，但畫面互動性較差，之後要做 App 也沒辦法共用

## 影響

- 前後端可以分開開發、分開部署
- 以後做手機 App 或和其他系統串接，可以共用同一套 API
- 要維護兩個專案，並設定 CORS
- API 規格要寫清楚，用 OpenAPI 文件讓前端對照
- 前台和後台要做成一個網站還是兩個，等前端計畫再決定
