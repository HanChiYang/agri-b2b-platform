# ADR-0010：可以有多位管理員，權限都相同

- 狀態：已接受
- 日期：2026-10-24

## 背景

後台會有多位公司內部人員一起處理訂單和商品，但目前不需要區分誰能做什麼。

## 決策

- 所有管理員都用同一個 `Admin` 角色，沒有更細的權限設定
- 系統第一次啟動時，依設定檔建立第一位管理員；之後由管理員在後台新增其他管理員
- 管理員不能停用自己，所以系統一定會留下至少一位啟用中的管理員
- 管理員帳號不刪除，只停用
- 訂單狀態歷程記錄是哪一位管理員操作的

## 考慮過的其他方案

- 分級權限（例如有人只能看訂單、不能改商品）：要設計權限資料表和設定畫面，目前用不到
- 所有人共用一個管理員帳號：沒辦法記錄是誰操作的，有人離職時也只能改密碼

## 影響

- 每位管理員都能做所有後台操作，包含新增和停用其他管理員
- 之後要分級權限時，可以把角色改成權限清單，後台 API 改成依權限檢查
