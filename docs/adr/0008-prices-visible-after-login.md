# ADR-0008：商品與價格要登入才看得到

- 狀態：已接受
- 日期：2026-10-24

## 背景

價格只給合作經銷商看，不希望公開。

## 決策

- 商品和分類的 API 都要登入才能呼叫
- 訪客只能讀取網站內容（公司簡介、聯絡資訊）和呼叫登入 API

## 考慮過的其他方案

- 商品公開，價格登入才看得到：可以當產品型錄對外宣傳，但同一支 API 要依登入狀態回傳不同欄位
- 商品和價格全部公開：不符合只給經銷商看價格的需求

## 影響

- 權限規則單純：除了網站內容和登入，其他 API 都要登入
- 想讓潛在客戶看到產品，要另外寫在公司簡介裡
- 之後要改成「商品公開、價格隱藏」，只需要調整商品 API 的權限和回傳欄位
